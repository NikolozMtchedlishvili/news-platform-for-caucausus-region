# news-platform-for-caucausus-region
This project addresses the lack of a centralized English-language news source for the Southern Caucasus region. Many important regional developments are published only in local languages and across fragmented outlets, making them hard to follow geopolitical and economic developments for audiences such as international investors.

# Using Python and JavaScript, I built an automated system that:
- Scrapes news articles from multiple regional sources
- Translates them into English
- Processes and structures the data
- Publishes the content dynamically on a website

# Project Structure
- manage-live-news/     # Backend (Python)
- live-news/            # Frontend (Website)

# Backend: manage-live-news/

# Responsibilities
- Crawls and scrapes multiple regional news outlets
- Extracts article content and metadata
- Translates articles into English
- Generates images/thumbnails for articles
- Stores processed data in a structured format (data.txt)
- Programmatically updates frontend content

# Frontend: live-news/

# Responsibilities
- Displays scraped and translated news articles
- Dynamically renders content updated by the backend
- Provides a clean and accessible UI for readers

# Impact & Results
- Solved a real information accessibility gap for international audience
- Fully automated end-to-end pipeline (scrape → translate → publish)
- Reached 1,000+ users within weeks of launch
- Designed for scalability (easy to add new news sources)
